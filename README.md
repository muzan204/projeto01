## ⚡ Sobre o projeto

A **Calculadora Neon Cyberpunk** é um projeto front-end criado com HTML, CSS e JavaScript puro, com foco em:

- Lógica de programação  
- Manipulação do DOM  
- Estilização moderna  
- UI futurista estilo cyberpunk  

---

## 🎯 Funcionalidades

✔️ Soma, subtração, multiplicação e divisão  
✔️ Botão limpar (C)  
✔️ Resultado automático (=)  
✔️ Interface neon estilizada  
✔️ Efeitos hover nos botões  

---

## 🎨 Visual do projeto

- 🌌 Fundo escuro estilo futurista  
- 💚 Tela com brilho neon  
- 🟣 Botões com gradientes modernos  
- ✨ Animações suaves e hover glow
